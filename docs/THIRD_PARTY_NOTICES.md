# Third-party notices and intake register

No third-party binaries, model weights, voices, fonts, brushes, textures, plugins, model outputs, or sample art are bundled at this stage.

Before adding a dependency, record:
- component and version/commit
- original repository and upstream URL
- software license and exact license file
- model/data/font/voice/asset licenses separately
- copyright/attribution and NOTICE requirements
- modifications, patches, build flags and transitive dependencies
- supported platforms and architecture
- security and vulnerability status
- compatibility/prototype results
- package size, memory and performance observations
- replacement/rollback plan
- reviewer and review date

A repository being public or labelled "open source" is not proof that its weights, fonts, voice, datasets or sample content may be redistributed. Restrictive, non-commercial, unclear or incompatible licenses must be escalated before adoption.
